# Турецкий в банке · Alterna Timur

Лексический гайд «В банке» на турецком (şube, sıramatik, hesap, vergi numarası, havale / FAST / EFT, dekont, masraf, şifre, taksit, döviz, alış / satış) в сторителлинг-формате + витрина платформы **Alterna Timur A0→C1**.

- Дизайн в стиле Vare: чёрный / мятный #00FFCC / белый, Inter Tight, пилюли, problem/solution-карточки
- Mobile-first, без зависимостей (vanilla HTML/CSS/JS)
- Озвучка через Web Speech API (tr-TR)
- Инфографика и диаграммы: маршрут по банку (scroll-linked), анатомия IBAN, схема havale/FAST/EFT с режимами день/ночь/выходные, график «когда работает» с живым временем Стамбула, табло обменника alış/satış, бар-чарт состава платформы, карта уровней A0→C1, бегущие строки, анимация заголовков
- Интерактив: 3D-карта, турецкая клавиатура, конструктор «-mak istiyorum», 40 карточек-переворотов по 5 зонам, приложение банка с переводом, диалог у окошка с ветвлениями, тест с конфетти, стена Notion-скринов с подсветкой, видео, веер телефонов, калькулятор цены
- Реальные скриншоты и записи платформы в `media/`
